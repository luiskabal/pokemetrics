Game Boy player: licenses and source

The player runs locally in an independent iframe. No commercial game ROMs or Nintendo BIOS files are distributed with Pokémetrics. These licenses cover emulator software, not game content.

  • EmulatorJS 4.2.3 — Copyright Ethan O’Brien and contributors. GNU GPL v3 or later. Upstream source at v4.2.3. Distributed source and runtime. The minified JavaScript was generated from the included src/ files with Terser; no emulator functionality was modified. Only the Game Boy core and the English, Spanish and Japanese translations are included.
  • Gambatte / RetroArch WebAssembly core — EmulatorJS core package 4.2.3, core interface 2.0.2; official build dated 2025-06-14. Core and bundled component license notices. Gambatte source, RetroArch source, build scripts, original core distribution.
  • nipplejs — Copyright Yoann Moinet. MIT license. Source.
  • Socket.IO — Copyright Guillermo Rauch and contributors. MIT license. Source. Online multiplayer is not enabled.
  • 7-Zip extraction worker — Included unchanged from EmulatorJS 4.2.3; used to load the distributed core. Distributed source, upstream source. Game uploads accept uncompressed GB/GBC files.
